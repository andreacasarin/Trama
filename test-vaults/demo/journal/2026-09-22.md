# 2026-09-22 — Exact words still matter

I nearly described semantic search as the replacement for keyword search. That would have been a poor explanation of what we are building.

Technical writing is full of terms that matter precisely: SQLite, OPFS, model identity, publication. If I remember one of those words, I want a direct route back to it. [[Lexical search remembers exact words]] now captures this more honestly.

The interesting comparison is not old search versus new search. It is two useful clues working together. [[Hybrid search combines clues]] gives me a better way to explain that distinction.

For the demo, try “SQLite FTS” first, then a question about finding a concept without remembering the wording. The same notebook should support both. I also want to show opening the source note; a search result that never returns me to writing is only half a workflow.
