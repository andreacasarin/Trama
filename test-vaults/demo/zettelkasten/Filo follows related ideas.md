# Filo follows related ideas

Filo starts from the note I am reading rather than a query I have composed. Its value is discovery: another note may belong in the same line of thought even when I did not remember to search for it.

This works especially well in a Zettelkasten. Atomic notes give relatedness something specific to work with, while explicit links record the connections I have already chosen. Suggested neighbors and authored links serve different purposes.

For a demo, opening the note about embedding cache reuse should lead naturally toward exact inputs and model identity. The point is not a magical recommendation; it is a lower-friction way to notice a useful connection.
