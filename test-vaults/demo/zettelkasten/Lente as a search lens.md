# Lente as a search lens

Lente is the part of Trama I reach for when I want to find something deliberately. I bring a word, a question, or a hazy memory and inspect candidate notes.

For a first demo, an exact query such as “embedding cache” is easy to follow. A second query can describe the same idea indirectly: “avoid asking the model about unchanged text.” The contrast explains lexical and semantic retrieval without starting with vector mathematics.

The result is not the end of the interaction. Opening the source note lets me check the excerpt, read neighboring context, and continue writing. Search should shorten that route back into the notebook.
